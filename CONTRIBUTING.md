# Contributing

Thanks for contributing.

## Development Setup

1. Fork and clone the repository.
2. Install dependencies:

```bash
npm install
```

3. Run dev server:

```bash
npm run dev
```

## Branching

- Create focused branches from `main`.
- Use branch names like `feature/portal-search` or `fix/chunk-sync`.

## Pull Requests

- Keep PRs small and focused.
- Include a clear summary of behavior changes.
- Add manual test notes (Quest/browser steps).
- Link issues when applicable.

## Coding Guidelines

- Keep changes scoped to the task.
- Preserve existing style and architecture.
- Avoid unrelated reformatting.
